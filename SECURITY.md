# Security and data boundaries

The public deployment is a static portfolio demonstration with disposable synthetic data. It does not run the historical application's server routes or connect to its former providers. Do not enter personal, customer or agency records.

The authenticated application is provided for local code review. Read `RECOVERY.md` and `DEPENDENCIES.md` before considering any deployment with real users. Passing the listed tests is not a comprehensive security audit.

This independent public edition excludes the original Git history and historical uploaded media. No credentials should be committed. Use your own newly provisioned development credentials through ignored environment files. Removing source or Git history does not revoke a previously exposed credential.
